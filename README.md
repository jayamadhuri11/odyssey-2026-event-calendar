
# ODYSSEY 2026 — Event Calendar

A customized event calendar for ODYSSEY 2026, featuring event dates, a countdown timer, and event information.

## Features

- ODYSSEY 2026 event landing page
- Countdown to the event start
- October 2026 event calendar
- E-Expo completed event details
- ODYSSEY Day 1 and Day 2 information
- Responsive layout for desktop and mobile screens

## Events

- October 16, 2026 — E-Expo (Completed)
- October 29, 2026 — ODYSSEY Day 1
- October 30, 2026 — ODYSSEY Day 2

**Venue:** CV Raman Hall

## Technologies Used

- HTML
- CSS
- JavaScript
- jQuery
- Evo Calendar

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep the `evo-calendar` folder in the same project directory so the calendar assets load correctly.
